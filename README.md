# اسم و فامیل آنلاین

## اجرای آزمایشی روی کامپیوتر
1. Node.js نسخه 18 یا بالاتر نصب باشد.
2. داخل پوشه پروژه دستور `npm install` را اجرا کنید.
3. دستور `npm start` را اجرا کنید.
4. در مرورگر `http://localhost:3000` را باز کنید.

برای تست چندنفره در یک شبکه، از دستگاه‌های دیگر با IP کامپیوتر میزبان و پورت 3000 وارد شوید.

## انتشار روی اینترنت (Render)
1. یک حساب در GitHub و Render بسازید.
2. محتوای این پوشه را در یک مخزن GitHub بارگذاری کنید.
3. در Render گزینه New > Web Service را بزنید و مخزن را متصل کنید.
4. Build Command: `npm install`
5. Start Command: `npm start`
6. پس از Deploy، Render یک نشانی عمومی HTTPS می‌دهد؛ آن را برای دوستان بفرستید.

این پروژه سرور Node.js و Socket.IO دارد؛ اتاق‌ها، ورود بازیکنان، زمان‌سنج، ثبت جواب، چت و امتیازدهی روی سرور انجام می‌شود.

## نکات نسخه اولیه
- ظرفیت هر اتاق ۱۰ نفر است.
- حداقل ۲ نفر برای شروع لازم است.
- زمان هر دور ۶۰، ۹۰ یا ۱۲۰ ثانیه است.
- پاسخ‌هایی امتیاز می‌گیرند که با حرف دور شروع شوند؛ پاسخ یکتا ۱۰ و پاسخ تکراری ۵ امتیاز دارد.
- این نسخه ذخیره دائمی حساب‌ها و اتاق‌ها ندارد؛ با ری‌استارت سرور اتاق‌ها پاک می‌شوند.
